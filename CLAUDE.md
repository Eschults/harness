# Project conventions

The rules every Claude Code run in this repository follows live in the harness rulebook, loaded here:

@.claude/harness-rules.md

This file is the one you own. Repo-specific conventions, and additions to the rulebook's never-edit and stop-topic lists, go below; a harness upgrade never touches them.

## This repo

This repository *is* the harness, so `.claude/harness-rules.md` is the source here rather than a vendored copy. Changing it is a normal code change and goes through review like any other — the "do not edit this file" line in it is addressed to repositories that installed the harness.

There is no test suite. Say so in a PR description rather than inventing one.
